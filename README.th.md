# ตัวกรองโฆษณาแบบเบาสำหรับ Loon บน iPhone และ iPad

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Tiếng Việt](README.vi.md) · **ไทย** · [Bahasa Indonesia](README.id.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Español](README.es.md) · [العربية](README.ar.md)

นี่คือชุดกฎที่ฉันใช้บน iPhone และ iPad ผ่านลิงก์สมัครรับเพียงลิงก์เดียว เหมาะกับคนที่ใช้เว็บและแอปจีนอย่าง JD, Taobao และ Meituan เป็นประจำ รวมถึงนักศึกษาต่างชาติในจีน เมื่อชื่อโฮสต์ตรงกับโดเมนโฆษณาในรายการทุกตัวอักษร Loon จะบล็อกคำขอบนอุปกรณ์ หากต้องการกรองโฆษณาที่แทรกในแอปบางส่วน ก็เลือกเปิดกฎเขียนข้อมูลใหม่บนอุปกรณ์เฉพาะคำขอที่กำหนดไว้ได้

## การติดตั้ง

**[ติดตั้งปลั๊กอินแบบครบในตัว](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2Flingjieheti%2Floon-adlite%2Fmain%2FiPad-AdSuite.lpx)** · [ลิงก์สมัครรับอัปเดต](https://raw.githubusercontent.com/lingjieheti/loon-adlite/main/iPad-AdSuite.lpx)

เปิดลิงก์ติดตั้งใน Safari แล้วยืนยันการนำเข้าใน Loon หรือวางลิงก์สมัครรับอัปเดตใน Configuration → Plugins → ＋ การบล็อกตามชื่อโฮสต์ใช้ได้โดยไม่ต้องติดตั้งใบรับรอง ปลั๊กอินประมวลผลบนอุปกรณ์ ไม่โหลดสคริปต์จากภายนอกและไม่เก็บข้อมูลการใช้งาน

หากสมัครรับรุ่น Suite อยู่แล้ว ให้รีเฟรชรายการเดิมได้เลย หากเคยใช้ปลั๊กอินบล็อกโฆษณาตัวอื่นของโครงการนี้ ให้เปิดรุ่นครบในตัวแล้วปิดรายการเดิม เพื่อไม่ให้กฎทำงานซ้ำกัน

## โฆษณาที่แทรกในแอป

หากต้องการกรองโฆษณาบางส่วนในบทความจากบัญชีทางการของ WeChat หรือฟีดหน้าแรกของ Bilibili ให้ใช้ Loon 3.5.1 (บิลด์ 978) ขึ้นไป เปิด Rewrite และการถอดรหัส HTTPS สำหรับโฮสต์ที่ระบุ แล้วตั้งค่าให้อุปกรณ์เชื่อถือใบรับรอง Loon ที่คุณสร้างเอง คำขออื่นไปยังโฮสต์เดียวกันก็อาจถูกถอดรหัส การเชื่อมต่อและประมวลผลจึงอาจใช้เวลาเพิ่ม [คู่มือการถอดรหัสของ Loon](https://nsloon.app/docs/MitM/)

กฎสำหรับฟีดแนะนำของ Douyin ผ่านการทดสอบด้วยข้อมูลตัวอย่างแล้ว ยังต้องตรวจสอบผลกับแอปรุ่นปัจจุบันบนอุปกรณ์จริง ส่วนโฆษณาที่ตัดต่อมากับวิดีโอต้องกดข้ามเอง

## เครื่องมือเสริมสำหรับ Safari

ตัวช่วยบนเว็บ YouTube จะลองกดปุ่มข้ามโฆษณาเมื่อปุ่มของ YouTube ปรากฏ อีกเครื่องมือหนึ่งช่วยซ่อนพื้นที่โฆษณาบางแห่งบน Pornhub [ติดตั้งตัวช่วย YouTube](https://raw.githubusercontent.com/lingjieheti/loon-adlite/main/youtube/youtube.user.js) · [ติดตั้งตัวช่วยสำหรับเว็บไซต์](https://raw.githubusercontent.com/lingjieheti/loon-adlite/main/web/pornhub.user.js) · [ดาวน์โหลด Userscripts](https://apps.apple.com/app/id1463298887)

## การอัปเดต

GitHub เปรียบเทียบรายชื่อโฮสต์โฆษณากับแหล่งต้นทางทุกวันและตรวจสอบความปลอดภัยทุกครั้ง หากรายชื่อโฮสต์ที่อนุมัติมีการเปลี่ยนแปลง ระบบจะเผยแพร่ที่ลิงก์สมัครรับเดิมโดยอัตโนมัติเมื่อผ่านการตรวจสอบและการทดสอบทั้งหมดแล้ว แหล่งที่มาของกฎกรองโฆษณาภายในแอปอย่าง Bilibili และ JD ก็ได้รับการตรวจสอบทุกวัน หากต้องแก้กฎ จะมีการตรวจสอบความปลอดภัยแยกอีกครั้งก่อนเผยแพร่

ลิงก์สมัครรับอัปเดตใช้สาขา `main` ตั้งค่าให้ Loon ตรวจสอบทรัพยากรภายนอกทุกวันได้ หากต้องการย้อนกลับ ให้แทนที่ `main` ในลิงก์ด้วยแฮชแบบเต็มของคอมมิตที่ต้องการ [ดูประวัติการแก้ไข](https://github.com/lingjieheti/loon-adlite/commits/main/)
