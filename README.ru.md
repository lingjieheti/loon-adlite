# Мой фильтр рекламы для Loon — всё в одном

Я пользуюсь этим плагином на iPhone и iPad и делюсь им с теми, кто часто открывает китайские приложения, в том числе с иностранными студентами в Китае. Правила рассчитаны на часть рекламы при запуске JD, Taobao и Meituan. Они также блокируют запросы сайтов к известным рекламным серверам.

## Установка

**[Установить единый плагин](https://www.nsloon.com/openloon/import?plugin=https%3A%2F%2Fraw.githubusercontent.com%2Flingjieheti%2Floon-adlite%2Fmain%2FiPad-AdSuite.lpx)** · [Адрес подписки](https://raw.githubusercontent.com/lingjieheti/loon-adlite/main/iPad-AdSuite.lpx)

Откройте ссылку в Safari и подтвердите импорт в Loon. Можно также вставить адрес подписки в Configuration → Plugins → ＋. Для блокировки по имени хоста сертификат не нужен. Плагин обрабатывает трафик на устройстве, не загружает удалённые скрипты и не собирает данные об использовании.

Если у вас уже есть подписка на версию Suite, просто обновите её. Если вы пользовались другим плагином этого проекта для блокировки рекламы, отключите его после включения единого плагина, чтобы правила не дублировались.

## Реклама внутри приложений

Чтобы отфильтровать часть рекламы в статьях официальных аккаунтов WeChat и в ленте Bilibili, используйте Loon 3.5.1 (сборка 978) или новее. Включите перезапись и расшифровку HTTPS для перечисленных хостов и добавьте собственный сертификат Loon в доверенные на устройстве. Другие запросы к тем же хостам тоже могут расшифровываться. Установка соединения и обработка ответа занимают дополнительное время. [Документация Loon по расшифровке](https://nsloon.app/docs/MitM/)

Правила для ленты рекомендаций Douyin проверены на образцах ответов. Их работу в текущей версии приложения ещё предстоит проверить на устройстве. Рекламные вставки, записанные в самом видео, нужно пропускать вручную.

## Обновления

GitHub ежедневно сверяет рекламные домены с источником и каждый раз проводит аудит безопасности. Изменения в списке одобренных доменов автоматически публикуются по прежнему адресу подписки только после успешного аудита и прохождения всех тестов. Источники правил для встроенной рекламы в таких приложениях, как Bilibili и JD, также проверяются ежедневно. Изменения этих правил проходят отдельную проверку безопасности перед публикацией.

Подписка обновляется из ветки `main`. В Loon можно включить ежедневную проверку внешних ресурсов. Для возврата к старой версии замените `main` в адресе подписки полным хешем нужного коммита. [История изменений](https://github.com/lingjieheti/loon-adlite/commits/main/)
